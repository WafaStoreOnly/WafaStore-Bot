📚 Tutor Via Gamepass (Rate 14k/100 - Cair 7 Hari):

🧮 Kalkulator Gamepass:
Mau terima 1000 R$ bersih, pasang harga di Roblox:
1.429 R$
Rumus: Jumlah / 0.7 = Harga Gamepass (Roblox potong 30%)
Contoh 774 R$ = 774 / 0.7 = 1106 R$
  1. Buka roblox.com > Login > Klik Create
  2. Pilih Manage My Experiences > Pilih map kamu (bebas)
  3. Klik Associated Items > Passes > Create a Pass
  4. Upload gambar bebas, nama "Donasi WafaStore" > Create
  5. Klik Pass yang barusan > Sales > Aktifkan Item for Sale
  6. Isi harga sesuai kalkulator di atas! Contoh mau 774 R$, isi 1106
  7. Copy link Gamepass, paste di kolom Link Gamepass di atas
  8. Order WA, Robux cair setelah 7 hari pending Roblox (paling murah!)
